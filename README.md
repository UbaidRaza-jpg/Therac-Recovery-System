# Therac Recovery System

A Risk-Validated Workflow Simulator inspired by the Therac-25 software engineering case study.

## Features

- Workflow Step Management
- Directed Graph Connections
- Safety Validation
- Risk Scoring System
- Undo Functionality
- Binary Save & Load
- Safety Report Export

## Data Structures Used

- Doubly Linked List
- Singly Linked List
- Stack
- Graph (Adjacency List)
- Arrays

## Technologies

- C++
- Object-Oriented Programming
- File Handling
- Data Structures & Algorithms

## How to Run

```bash
g++ *.cpp -o therac
therac
```
